# 页面结构和文案存储

本文件夹用于存储项目中所有页面的结构和文案内容，便于未来更新页面主题和架构。

## 项目概述

彼励扶跨境电商网站的页面结构和文案已完整提取并整理为JSON格式文件，包括：
- 所有公共页面（首页、服务、关于、联系、新闻）
- 管理后台系统
- 导航栏和Footer等公共组件

## 文件说明

- `README.md` - 本说明文档
- `overview.md` - 项目页面结构和文案总览
- `home.json` - 首页页面结构和文案
- `service.json` - 服务页面结构和文案
- `about.json` - 关于页面结构和文案
- `contact.json` - 联系页面结构和文案
- `news.json` - 新闻页面结构和文案
- `admin.json` - 管理后台页面结构和文案
- `navigation.json` - 导航栏结构和文案
- `footer.json` - Footer组件结构和文案

## 使用方法

1. **查看页面结构**: 打开对应的JSON文件，查看页面的区块结构和文案内容
2. **修改文案**: 直接编辑JSON文件中的文本内容
3. **更新结构**: 如需调整页面结构，修改JSON中的sections部分
4. **添加新内容**: 参考现有结构，在相应sections中添加新的内容

## JSON结构说明

每个JSON文件遵循统一的基本结构：
- `page`: 页面名称
- `meta`: 页面元信息（标题、描述等）
- `sections`: 页面区块列表，每个区块包含名称、标题、内容等

## 注意事项

- 修改JSON文件时请保持语法正确
- 建议在修改前备份原文件
- 修改后需要在代码中相应更新引用
- 图片资源路径需要保持一致

更多详细信息请参考 [overview.md](overview.md) 文件。
