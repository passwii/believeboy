## 内容概览

### design-system.md 包含：
1. **设计原则** - 品牌调性、关键词、设计语言
2. **色彩系统** - 主色调、辅助色、中性色、语义色、渐变规范
3. **字体系统** - 字体选择、字号层级、字重规范
4. **间距系统** - 间距基准、页面边距、Grid系统
5. **组件规范** - 按钮、卡片、输入框、导航栏、标签徽章
6. **动画规范** - 动画原则、时长、缓动函数、页面过渡
7. **页面布局** - 首页布局、通用页面布局、各页面组件位置
8. **响应式规范** - 断点策略、移动端特殊处理
9. **设计资源** - Tailwind 配置参考、CSS 变量
