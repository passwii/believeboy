# X 套餐 Section 设计方案

## 一、设计目标

为「联合运营品牌出海计划（X套餐）」设计一个高端、专业、具有视觉冲击力的专属展示 section，突出其**合伙人级共创模式**的独特定位，与标准套餐形成明显区隔。

## 二、核心卖点提炼

### 2.1 四大独特价值
1. **资产导向** - 输出可复制、可溢价、可退出的品牌资产
2. **场景适配** - 有无店铺皆可，从0搭建或升级转型
3. **回报可期** - 短期溢价20-50%，长期资产增值
4. **高性价比** - 25.8万/年战略投资，效果分成绑定

### 2.2 八大服务模块
品牌DNA → 全球IP → 店铺矩阵 → 选品 → 广告营销 → 库存履约 → 内容增长 → 专属团队

## 四、视觉效果设计

### 4.1 背景设计
- **主背景**: `bg-slate-950` (#020617) - 比标准slate-900更深的高端黑
- **渐变叠加**: 
  - 左上角: `bg-gradient-to-br from-amber-500/5 via-transparent to-transparent` (金色微光)
  - 右下角: `bg-gradient-to-tl from-cyan-500/10 via-transparent to-transparent` (科技蓝光)
- **粒子效果**: 金色+蓝色粒子缓慢浮动，密度比Hero区低30%

### 4.2 光效设计
```css
/* 顶部光晕 */
.top-glow {
  background: radial-gradient(ellipse 80% 50% at 50% -20%, rgba(245, 158, 11, 0.15), transparent);
}

/* 底部光晕 */
.bottom-glow {
  background: radial-gradient(ellipse 60% 40% at 50% 120%, rgba(6, 182, 212, 0.1), transparent);
}
```

### 4.3 卡片效果
- **玻璃态**: `bg-white/5 backdrop-blur-xl border border-white/10`
- **悬停**: `hover:bg-white/10 hover:border-white/20 hover:shadow-2xl hover:shadow-cyan-500/10`
- **金色强调**: 边框或顶部装饰线使用 `from-amber-400 to-amber-600`

## 七、响应式设计

### 7.1 断点策略
| 断点 | 布局变化 |
|------|----------|
| Desktop (≥1280px) | 完整布局，4列价值卡片，时间轴展开 |
| Tablet (768-1279px) | 2列布局，时间轴简化 |
| Mobile (<768px) | 单列堆叠，时间轴改为垂直或网格 |

### 7.2 关键适配
- **价值卡片**: Desktop 4列 → Tablet 2列 → Mobile 1列
- **服务时间轴**: Desktop横向 → Mobile改为4x2网格或垂直列表
- **定价区域**: 保持居中，价格字号响应式缩小
- **CTA按钮**: Mobile全宽堆叠

## 八、交互细节

### 8.1 入场动画序列
```
0ms    - 背景粒子开始浮动
200ms  - Badge淡入
400ms  - 主标题淡入 + 上滑
600ms  - 副标题淡入
800ms  - 价值卡片依次进入 (stagger 100ms)
1200ms - 服务时间轴展开
1500ms - 定价区域发光效果
```

### 8.2 悬停效果
- **价值卡片**: 边框发光 + 轻微上移 + 图标放大
- **服务节点**: 节点高亮 + 连接线流动效果
- **CTA按钮**: 金色光晕扩散 + 文字高亮
- **背景**: 鼠标跟随轻微视差效果

### 8.3 滚动效果
- 进入视口时触发入场动画
- 服务时间轴随滚动逐步展开
- 定价数字可考虑滚动计数动画

## 九、实现建议

### 9.1 文件结构
```
app/(marketing)/pricing/sections/
├── x-package-section.tsx          # 主组件
├── components/
│   ├── value-card.tsx             # 价值卡片
│   ├── service-timeline.tsx       # 服务时间轴
│   ├── glow-button.tsx             # 发光按钮
│   └── particle-background.tsx     # 粒子背景
└── hooks/
    └── use-mouse-parallax.ts       # 鼠标视差
```

### 9.2 依赖建议
- `framer-motion` - 入场动画、悬停效果
- `react-particles` 或 `tsparticles` - 粒子背景
- `@number-flow/react` - 数字滚动动画

### 9.3 性能优化
- 粒子效果使用 canvas，避免 DOM 操作
- 动画使用 transform 和 opacity，避免触发重排
- 图片懒加载，非首屏内容延迟加载
- 支持 `prefers-reduced-motion`，减少动画

## 十、设计亮点总结

1. **视觉层级**: 深色背景 + 金色强调 + 科技蓝光，营造高端VIP感
2. **信息架构**: 价值 → 服务 → 定价 → CTA，逻辑清晰
3. **交互体验**: 滚动触发、悬停反馈、入场动画，增强沉浸感
4. **品牌调性**: 专业可信、科技前沿、合伙人级共创理念
