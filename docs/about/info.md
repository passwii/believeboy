## 页面结构

该页面由以下主要区块组成：

### 1. HeroSection（顶部横幅）
- **位置**: 页面顶部，全屏高度
- **内容**: 展示公司定位和愿景

### 2. CompanySection（公司介绍）
- **位置**: Hero 下方
- **内容**: 公司背景、使命、愿景

### 3. TeamStatsSection（团队数据）
- **位置**: 公司介绍下方
- **内容**: 团队规模、经验、成果数据
- **数据来源**: `app/(marketing)/about/modules/team-stats/data.ts`

### 4. CoreValuesSection（核心价值）
- **位置**: 团队数据下方
- **内容**: 四大核心价值理念
- **数据来源**: `app/(marketing)/about/modules/core-values/data.ts`

#### 四大核心价值

1. **战略先于执行**
   - 描述：所有投放、选品、内容动作都从品牌阶段目标反推，避免无效增长。
   - 颜色：天空蓝到深蓝 `from-sky-500 to-blue-600`

2. **AI嵌入日常运营**
   - 描述：把AI用在关键词、创意、定价和复盘中，让团队把时间留给关键判断。
   - 颜色：青色到深青 `from-cyan-500 to-teal-600`

3. **指标透明到日**
   - 描述：建立统一增长看板，持续追踪流量质量、转化效率、利润结构和复购。
   - 颜色：翠绿到深绿 `from-emerald-500 to-green-600`

4. **共担结果的伙伴关系**
   - 描述：不做外包思维的短期协作，而是与品牌共建可持续、可复制的出海体系。
   - 颜色：靛蓝到天蓝 `from-indigo-500 to-sky-600`

### 5. CooperationIdeasSection（合作理念）
- **位置**: 核心价值下方
- **内容**: 合作模式、合作理念
- **数据来源**: `app/(marketing)/about/modules/cooperation-ideas/data.ts`

### 6. CTASection（行动召唤）
- **位置**: 页面底部
- **内容**: 引导用户联系合作

## 核心价值理念

### 战略先于执行
- **理念**: 所有动作从目标反推
- **实践**: 避免无效增长，确保投入产出

### AI嵌入日常运营
- **理念**: AI辅助关键环节
- **实践**: 关键词、创意、定价、复盘自动化

### 指标透明到日
- **理念**: 数据驱动决策
- **实践**: 统一增长看板，持续追踪关键指标

### 共担结果的伙伴关系
- **理念**: 长期合作伙伴
- **实践**: 共建可持续、可复制出海体系
