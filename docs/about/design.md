# 关于我们 - 页面设计

## 设计概述

关于我们页面采用专业开放的风格，通过清晰的价值观展示和团队介绍，建立彼励扶的专业形象和可信度。

## 色彩系统

### 主色调
- **背景色**: 深色和浅色交替
- **强调色**: 多彩主题（天空蓝、青色、翠绿、靛蓝）

### 核心价值卡片配色系统

#### 战略先于执行
- **渐变**: `from-sky-500 to-blue-600`

#### AI嵌入日常运营
- **渐变**: `from-cyan-500 to-teal-600`

#### 指标透明到日
- **渐变**: `from-emerald-500 to-green-600`

#### 共担结果的伙伴关系
- **渐变**: `from-indigo-500 to-sky-600`

## 布局结构

### Hero Section
- 全屏高度
- 居中布局
- 主标题 + 副标题 + 描述

### 公司介绍
- 宽幅布局
- 图文结合
- 左右交替布局

### 团队数据
- 数据统计卡片
- 网格布局
- 数字突出显示

### 核心价值
- 四列卡片布局（桌面端）
- 响应式网格
- 图标 + 标题 + 描述

### 合作理念
- 分步展示
- 视觉化流程

## 组件设计

### 核心价值卡片
- **容器**: 卡片式布局
- **图标**: 大图标 + 渐变背景
- **标题**: 加粗显示
- **描述**: 浅色文字
- **间距**: `gap-6 lg:gap-8`

### 数据统计卡片
- **数字**: 大字体，渐变文字
- **标签**: 小字体，灰色
- **背景**: 渐变背景或卡片

## 动画效果

### 淡入动画 (FadeIn)
- **触发**: 滚动进入视口
- **延迟**: 0.1s 递增

### 滑入动画 (SlideUp)
- **触发**: 滚动触发
- **延迟**: 0.1s 递增

## 排版系统

### 标题
- **主标题**: `text-4xl md:text-5xl lg:text-6xl font-bold`
- **区块标题**: `text-2xl md:text-3xl font-semibold`
- **卡片标题**: `text-xl font-semibold`

### 正文
- **描述文字**: `text-lg`
- **卡片描述**: `text-sm`
- **统计数字**: `text-4xl md:text-5xl`

### 间距
- **区块垂直间距**: `py-20 md:py-24`
- **卡片间距**: `gap-6 lg:gap-8`

## 响应式设计

### 断点
- **移动端**: 单列布局
- **平板**: `md:` 双列布局
- **桌面**: `lg:` 四列布局

### 布局适配
- **核心价值**: `1列` → `md:2列` → `lg:4列`
- **数据统计**: 响应式网格
- **公司介绍**: 图文交替布局

## 可访问性

### 语义化 HTML
- 使用 `<section>` 标签签包裹区块
- 使用语义化的 heading 层级
- 列表使用 `<ul>` 标签

### 需色对比度
- 浅色文字在深色背景上确保可读性
- 卡片文字有足够对比度
