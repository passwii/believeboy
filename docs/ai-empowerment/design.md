# AI赋能 - 页面设计

## 设计概述

AI赋能页面采用科技智能风格，通过四大智能支柱的详细展示，突出彼励扶的AI技术能力和应用成果。

## 色彩系统

### 主色调
- **背景色**: 深色和浅色交替
- **强调色**: 多彩主题（青色、靛蓝、紫色、翠绿）

### AI支柱卡片配色系统

#### 视觉内容智能
- **渐变**: `from-cyan-500 to-blue-500`

#### 运营数据智能
- **渐变**: `from-indigo-500 to-violet-500`

#### 商业决策智能
- **渐变**: `from-violet-500 to-purple-500`

#### 协同管理智能
- **渐变**: `from-emerald-500 to-teal-500`

## 布局结构

### Hero Section
- 全屏高度
- 居中布局
- 主标题 + 副标题 + 描述

### AI愿景
- 宽幅布局
- 图文结合
- 左右交替布局

### 四大智能支柱
- 四列卡片布局（桌面端）
- 响应式网格
- 每个支柱包含：
  - 标题 + 副标题
  - 描述
  - 核心能力列表
  - 数据成果统计

### AI技术架构
- 图示展示
- 分层架构说明
- 技术栈介绍

### 实战应用场景
- 场景卡片
- 案例展示
- 流程图示

### AI工具订阅
- 价格卡片
- 功能对比
- 订阅选项

## 组件设计

### AI支柱卡片
- **容器**: 卡片式布局
- **图标**: 大图标 + 渐变背景
- **标题**: 加粗显示
- **副标题**: 次要文字
- **描述**: 浅色文字
- **能力列表**: 列表展示
- **数据统计**: 数值突出显示
- **间距**: `gap-6 lg:gap-8`

### 数据统计组件
- **对比展示**: Before vs After
- **数值**: 大字体，渐变文字
- **标签**: 小字体，灰色
- **突出变化**: 高亮显示优化成果

## 动画效果

### 淡入动画 (FadeIn)
- **触发**:① 滚动进入视口
- **延迟**: 0.1s 递增

### 滑入动画 (SlideUp)
- **触发**: 滚动触发
- **延迟**: 0.1s 递增

### 数据计数动画
- **数字递增**: 从0到目标值
- **时长**: 2-3秒
- **缓动**: easeOut

## 排版系统

### 标题
- **主标题**: `text-4xl md:text-5xl lg:text-6xl font-bold`
- **区块标题**:① `text-2xl md:text-3xl font-semibold`
- **卡片标题**: `text-xl font-semibold`
- **副标题**: `text-lg`

### 正文
- **描述文字**: `text-lg`
- **卡片描述**: `text-sm`
- **列表文字**: `text-xs`
- **统计数字**: `text-3xl md:text-4xl`

### 间距
- **区块垂直间距**: `py-20 md:py-24`
- **卡片间距**: `gap-6 lg:gap-8`
- **内部间距**: `space-y-4`

## 响应式设计

### 断点
- **移动端**: 单列布局
- **平板**: `md:` 双列布局
- **桌面**: `lg:` 四列布局

### 布局适配
- **AI支柱**: `1列` → `md:2列` → `lg:4列`
- **数据统计**: 响应式网格
- **AI愿景**: 图文交替布局

## 数据可视化

### 对比统计
- **Before**: 灰色显示，表示优化前
- **After**: 高亮显示，表示优化后
- **变化**: 需色编码，绿色（提升）
- **趋势**: 箭头指示提升方向

### 能力标签
- **列表样式**: 圆点或勾选标记
- **标签样式**: 轻微背景色
- **间距**: 均匀分布

## 可访问性

### 语义化 HTML
- 使用 `<section>` 标签签包裹区块
- 使用语义化的 heading 层级
- 列表使用 `<ul>` 标签

### 颜色对比度
- 浅色文字在深色背景上确保可读性
- 数据统计有足够对比度
