# 首页 - 页面设计

## 设计概述

首页采用深色科技风格，通过动态效果和丰富的视觉元素展示彼励扶的核心价值和服务能力。

## 色彩系统

### 主色调
- **背景色**: 深蓝色渐变 `radial-gradient(120%_80%_at_50%_0%,#13315f_0%,#081325_45%,#030712_100%)`
- **强调色**: 青色/蓝色渐变 `from-cyan-500 to-blue-500`
- **文字色**: 白色主标题、青色副标题、浅灰色正文

## 布局结构

### Hero Section
- 全屏高度
- 居中布局
- 主标题 + 副标题 + 描述文字
- 双按钮 CTA

### 其他区块
- 垂直堆叠布局
- 每个区块有独立的背景和内容
- 响应式网格布局

## 设计特点

- **动画**: 淡入、滑动、粒子效果
- **视觉**: 专业、科技感、高端
- **响应式**: 支持多设备
