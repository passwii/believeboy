# 服务介绍 - 页面设计

## 设计概述

服务介绍页面采用深色科技风格，通过全屏滚动、动态动画和多彩配色展示彼励扶的全链路跨境电商服务能力。

## 色彩系统

- **背景色**:

## 组件设计

### 按钮系统

#### 主要按钮 (CTA)
- **样式**: `bg-gradient-to-r from-cyan-500 to-blue-500`
- **尺寸**: `size="lg"`, `px-8 py-6 text-base`
- **效果**: 阴影 `shadow-lg`, hover 阴影 `shadow-xl`
- **交互**: hover 时渐变颜色变化，箭头右移动画

#### 次要按钮
- **样式**: `bg-white/10 border border-white/30`, backdrop-blur
- **尺寸**: 同主按钮
- **效果**: hover 时背景变亮

### 全屏滚动组件

#### ServiceScene (服务场景)
- **容器**: `w-screen h-screen`, 横向排列
- **布局**: `grid-cols-2 gap-16` (桌面端)
- **动画**: 滚动时淡入、缩放、位移

#### 导航指示器 (NavigationIndicator)
- **位置**: 右侧垂直居中
- **样式**: 圆点，激活时放大
- **交互**: 点击跳转到对应服务

#### 进度条 (ProgressBar)
- **位置**: 顶部
- **样式**: 细长进度条
- **颜色**: `from-blue-400 to-purple-400`
- **动画**: 弹簧效果跟随滚动

## 动画效果

### 全屏滚动动画
- **横向移动**: 使用 `framer-motion` 的 `useTransform` 实现平滑滚动
- **磁吸效果**: 滚动到最近的服务场景
- **弹簧动画**: 滚动进度使用弹簧效果，更自然

### 淡入动画 (FadeIn)
- **组件**: `FadeIn` from `@/components/effects/fade-in`
- **触发**: 滚动进入视口
- **延迟**: 0.1s 递增，创建层次感

### 滑入动画 (SlideUp)
- **组件**: `SlideUp`, `StaggerContainer`, `StaggerItem`
- **触发**: 滚动触发
- **方向**: 左侧元素从左滑入，右侧元素从右滑入

### 图标动画
- **主图标**: 垂直移动 `y: [0, -10, 0]` + 旋转 `rotate: [0, 5, -5, 0]`
- **次要图标**: 缩放 `scale: [1, 1.1, 1]` + 旋转 `rotate: [0, 10, 0]`
- **持续时间**: 3-5 秒循环

### 背景动画
- **渐变背景**: 透明度变化 `opacity: [0.5, 0.8, 0.5]`
- **光晕**: 缩放和透明度变化
- **网格**: 背景位置移动 `backgroundPosition: ['0px 0px', '100px 100px']`

### 标签动画
- **淡入**: 延迟 `0.4 + idx * 0.05` 递增
- **缩放**: `scale: [0.8, 1]`
- **创建**: 交错效果

## 响应式设计

### 断点
- **移动端**: 默认样式，单列布局，简化动画
- **平板**: `md:` 断点 (768px)
- **桌面**: `lg:` 断点 (1024px)

### 布局适配
- **Hero**: 文字大小、间距自适应
- **核心服务**:
  - 移动端: 简化显示
  - 桌面端: `grid-cols-2`, 全屏滚动效果
- **导航指示器**: 移动端隐藏或简化

## 滚动交互

### 滚动监听
- **使用**: `framer-motion` 的 `useScroll`
- **目标**: 核心服务容器
- **偏移**: `["start start", "end end"]`

### 滚动计算
- **当前页面**: `Math.round(exactPage)`
- **进度百分比**: `(currentPage / (serviceCount - 1)) * 100`
- **横向位移**: `0%` → `-${(serviceCount - 1) * 100}%`

### 导航点击
- **点击**: 导航圆点
- **计算**: 目标滚动位置
- **行为**: `window.scrollTo({ behavior: 'smooth' })`

## 可访问性

### 语义化 HTML
- 使用 `<section>` 标签包裹区块
- 使用语义化的 heading 层级
- 按钮包含可访问的文本标签
- 导航指示器使用 `<button>` 元素

### 颜色对比度
- 浅色文字在深色背景上确保可读性
- 按钮有足够的对比度
- 渐变背景保证文字清晰度

### 键盘导航
- 所有按钮可通过键盘访问
- Tab 键导航顺序合理
- 导航指示器支持键盘操作

### 屏幕阅读器
- 适当的 ARIA 属性
- 清晰的文本描述
- 有意义的链接文本

## 性能优化

### 动画优化
- 使用 `will-change-transform` 提示浏览器优化
- 使用 GPU 加速的属性 (`transform`, `opacity`)
- 避免重排和重绘

### 滚动性能
- 使用 `framer-motion` 的 `useSpring` 实现平滑滚动
- 避免高频事件监听器
- 使用 `requestAnimationFrame` 优化
