# 联系我们 - 页面设计

## 设计概述

联系我们页面采用专业友好的设计风格，通过清晰的表单布局、多彩的联系卡片和良好的用户体验设计，引导用户轻松完成咨询。

## 组件设计

### 表单设计

#### 表单容器
- **容器**: `Card` 组件
- **样式**: 阴影 `shadow-lg`, 边框 `border-0`
- **内边距**: `p-8`
- **背景**: 白色

#### 表单字段
- **标签**: `text-sm font-medium text-slate-700 mb-2`
- **输入框**: `Input` 组件
  - 高度: `h-9`
  - 图标左侧: `pl-10`
  - 错误状态: `border-red-500 focus-visible:ring-red-200`
- **文本域**: `Textarea` 组件
  - 最小高度: `min-h-[120px]`
  - 不可调整大小: `resize-none`

#### 表单验证
- **必填标识**: 红色星号 `<span className="text-red-500">*</span>`
- **错误提示**: `text-red-500 text-sm mt-1`
- **错误状态**: 输入框边框变红，聚焦环变红

#### 提交按钮
- **样式**: `bg-gradient-to-r from-blue-600 to-cyan-600`
- **大小**: `w-full h-12`
- **文字**: `text-white font-medium`
- **禁用状态**: 提交中时禁用
- **加载动画**: SVG 旋转动画
  ```svg
  <svg className="animate-spin h-4 w-4" viewBox="0 0 24 24">
    <circle className="opacity-25" cx="12" cy="12" r="10" />
    <path className="opacity-75" d="..." />
  </svg>
  ```

### 卡片设计

#### 联系信息卡片
- **容器**: `Card` 组件
- **样式**: 阴影 `shadow-sm`, hover `hover:shadow-md`
- **背景**: 白色
- **过渡**: `transition-shadow duration-300`
- **布局**: 水平布局，图标 + 文字

#### 图标容器
- **尺寸**: `w-12 h-12`
- **圆角**: `rounded-xl`
- **背景**: 渐变 `bg-gradient-to-br`
- **图标**: 白色，尺寸 `w-6 h-6`

#### 快速提示卡片
- **容器**: `rounded-xl p-6`
- **背景**: 蓝色 `bg-blue-50`
- **边框**: `border-blue-100`
- **布局**: 水平布局

## 交互设计

### 表单交互

#### 输入框图标
- **图标位置**: 左侧绝对定位
- **颜色**: `text-slate-400`
- **尺寸**: `w-4 h-4`

#### 输入反馈
- **验证时机**: `onChange` 事件
- **错误清除**: 输入时清除该字段的错误提示
- **提交验证**: 点击提交时验证所有必填字段

#### 提交状态
1. **初始状态**: 按钮可点击，显示"提交咨询"文字
2. **提交中状态**:
   - 按钮禁用
   - 显示加载动画
   - 文字改为"提交中..."
3. **提交成功**:
   - 显示成功提示（替换表单）
   - 图标：CheckCircle2
   - 背景：绿色圆圈
   - 消息："提交成功！感谢您的咨询..."
4. **提交失败**:
   - 显示 alert 提示
   - 按钮恢复可点击
   - 保留表单数据

### 卡片交互

#### 悬停效果
- **联系信息卡片**: 阴影增强 `hover:shadow-md`
- **过渡**: `transition-shadow duration-300`

## 动画效果

### 淡入动画 (FadeIn)
- **组件**: `FadeIn` from `@/components/effects/fade-in`
- **触发**: 滚动进入视口
- **延迟**: 0.1s 递增，创建层次感

### 滑入动画 (SlideUp)
- **组件**: `SlideUp` from `@/components/effects/slide-up`
- **触发**: 滚动触发
- **延迟**: 0.1s 递增

### 交错滑动动画 (Stagger)
- **组件**: `StaggerContainer`, `StaggerItem` from `@/components/effects/slide-up`
- **触发**: 滚动触发
- **延迟**: 0.1s 递增

### 加载动画
- **类型**: SVG 旋转动画
- **类名**: `animate-spin`
- **颜色**: 白色填充 `opacity` 25% + 75%

## 响应式设计

### 断点
- **移动端**: 默认样式，单列布局
- **平板**: `md:` 断点 (768px)
- **桌面**: `lg:` 断点 (1024px)

### 布局适配
- **Hero**: 文字大小、间距自适应
- **表单区块**:
  - 移动端: 单列布局
  - 桌面端: `lg:grid-cols-2`, 双列布局
  - 间距: `gap-12 lg:gap-16`

## 表单验证设计

### 验证规则
- **实时验证**: 输入时清除错误
- **提交验证**: 点击提交时验证所有字段
- **错误提示**: 字段下方显示红色错误文字
- **视觉反馈**: 错误字段边框变红

### 错误消息
- **姓名**: "请输入您的姓名"
- **联系电话**: "请输入有效的手机号码"
- **邮箱**: "请输入有效的邮箱地址"

## 可访问性

### 语义化 HTML
- 使用 `<section>` 标签包裹区块
- 使用 `<form>` 标签包裹表单
- 使用 `<label>` 标签关联输入框
- 使用语义化的 heading 层级

### 表单可访问性
- 所有必填字段有红色星号标识
- 输入框有描述性占位符
- 错误提示与输入框关联
- 提交按钮有明确的文字描述

### 键盘导航
- 所有输入框可通过 Tab 键导航
- 提交按钮可通过 Enter 键提交（表单内）
- Tab 键导航顺序合理

### 颜色对比度
- 浅色文字在深色背景上确保可读性
- 表单文字在白色背景上有足够对比度
- 错误提示使用红色，与正常状态区分明显

## 错误处理

### 表单验证错误
- **显示**: 字段下方红色文字
- **样式**: `text-red-500 text-sm mt-1`
- **触发**: 提交时验证失败

### 网络请求错误
- **显示**: alert 弹窗
- **消息**: "提交失败，请稍后重试"
- **处理**: 保留表单数据，允许重新提交
