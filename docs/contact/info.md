## 表单验证规则

### 必填字段
- 姓名：不能为空
- 联系电话：不能为空 + 中国手机号格式验证
- 邮箱：不能为空 + 邮箱格式验证

### 验证正则表达式
- **手机号**: `^1[3-9]\d{9}$`
- **邮箱**: `^[^\s@]+@[^\s@]+\.[^\s@]+$`

## 表单提交流程

1. 用户填写表单
2. 点击"提交咨询"按钮
3. 前端验证表单数据
   - 验证失败：显示错误提示，阻止提交
   - 验证成功：继续提交
4. 发送 POST 请求到 `/api/contact`
5. 等待服务器响应
   - 提交中：显示加载动画，禁用按钮
6. 接收服务器响应
   - 成功：显示成功消息，清空表单
   - 失败：显示错误提示，保留表单数据

## 数据接口

### 表单提交接口
- **URL**: `/api/contact`
- **Method**: `POST`
- **Headers**:
  - `Content-Type`: `application/json`
- **Body**:
  ```json
  {
    "name": "string",
    "company": "string",
    "phone": "string",
    "email": "string",
    "inquiryType": "string",
    "message": "string"
  }
  ```
- **Response**:
  ```json
  {
    "success": boolean,
    "error": "string" | null
  }
  ```
