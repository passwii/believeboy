# 定价方案 - 页面设计

## 设计概述

定价方案页面采用深色科技风格，通过专业、高端的视觉设计传达彼励扶的服务价值和专业性。

## 色彩系统

### 主色调
- **背景色**:
  - Hero: `radial-gradient(120%_80%_at_50%_0%,#13315f_0%,#081325_45%,#030712_100%)`
  - X 套餐区块: `#020617` (深蓝黑色)
  - 普通区块: `#f8fafc` (slate-50)

- **强调色**:
  - 主渐变: `from-cyan-500 to-blue-500`
  - X 套餐专属: `from-amber-500 to-amber-600` (琥珀金)
  - 次要渐变: `from-cyan-500 to-blue-600`

- **文字色**:
  - 主标题: `text-white`
  - 副标题: `text-cyan-400`
  - 正文: `text-white/70` / `text-slate-300`

### 光晕与粒子
- **Hero 区域光晕**:
  - 左上: `bg-cyan-400/20 blur-3xl`
  - 右上: `bg-blue-500/20 blur-3xl`
- **X 套餐光晕**:
  - 顶部: `rgba(245, 158, 11, 0.15)` 径向渐变
  - 底部: `rgba(6, 182, 212, 0.1)` 径向渐变
- **粒子效果**: 20 个动态粒子，青色和琥珀色交替，脉冲动画

## 组件设计

### 按钮系统

#### 主要按钮 (CTA)
- **样式**: `bg-gradient-to-r from-cyan-500 to-blue-500`
- **尺寸**: `size="lg"`, `px-8 py-6 text-base`
- **效果**: 阴影 `shadow-lg`, hover 阴影 `shadow-xl`
- **交互**: hover 时渐变颜色变化，箭头右移动画

#### 次要按钮
- **样式**: `bg-white/10 border border-white/30`, backdrop-blur
- **尺寸**: 同主按钮
- **效果**: hover 时背景变亮

#### X 套餐专属按钮
- **样式**: `bg-gradient-to-r from-amber-500 to-amber-600`
- **阴影**: `shadow-amber-500/25`
- **交互**: 更强的阴影效果和悬停反馈

### 卡片设计

#### 价格卡片
- **容器**: `rounded-2xl border border-white/10 bg-white/5 backdrop-blur-xl`
- **布局**: 网格布局，响应式 `grid-cols-1 md:grid-cols-3`
- **间距**: `gap-6 lg:gap-8`

#### X 套餐战略卡片
- **容器**: `rounded-3xl border border-amber-400/25`
- **背景**: `from-amber-500/10 via-slate-950/90 to-cyan-900/10`
- **阴影**: `shadow-[0_0_60px_-20px_rgba(245,158,11,0.35)]`
- **内边距**: `p-7 md:p-10 lg:p-12`

#### 核心价值卡片
- **容器**: `rounded-2xl border border-color/35 bg-slate-950/55`
- **背景**: 渐变叠加 `opacity-80`
- **交互**: hover 时向上移动 `-translate-y-1`，阴影增强

## 动画效果

### 淡入动画 (FadeIn)
- **组件**: `FadeIn` from `@/components/effects/fade-in`
- **触发**: 滚动进入视口
- **延迟**: 0.1s 递增，创建层次感

### 交错滑动动画 (Stagger)
- **组件**: `StaggerContainer`, `StaggerItem` from `@/components/effects/slide-up`
- **触发**: 滚动触发
- **延迟**: 0.1s 递增

### 粒子动画
- **效果**: 20 个粒子随机分布
- **动画**: 脉冲 `animate-pulse`
- **颜色**: 交替使用青色和琥珀色
- **随机性**: 位置、延迟、持续时间都是随机生成的

### 光晕动画
- **效果**: 大型模糊光晕
- **动画**: 缩放和透明度变化
- **持续时间**: 4-10 秒循环

### 卡片悬停
- **效果**: 向上移动、阴影增强、背景渐变变化
- **过渡**: `transition-all duration-300`
- **弹簧效果**: `y: -10` 位移

## 排版系统

### 标题
- **主标题**: `text-4xl md:text-5xl lg:text-6xl font-bold`
- **区块标题**: `text-2xl md:text-3xl font-semibold`
- **卡片标题**: `text-xl font-semibold`

### 正文
- **描述文字**: `text-lg text-white/70`
- **列表文字**: `text-sm text-slate-300`
- **标签文字**: `text-sm font-medium`

### 间距
- **区块垂直间距**: `py-20 md:py-24`
- **内容垂直间距**: `mb-6`, `mb-8`, `mb-10`
- **网格间距**: `gap-6 lg:gap-8`

## 响应式设计

### 断点
- **移动端**: 默认样式，单列布局
- **平板**: `md:` 断点 (768px)，双列布局
- **桌面**: `lg:` 断点 (1024px)，三列布局

### 布局适配
- **Hero**: 文字大小、间距自适应
- **价格卡片**: `grid-cols-1` → `md:grid-cols-3`
- **核心价值**: `grid-cols-1` → `md:grid-cols-2` → `xl:grid-cols-4`
- **服务模块**: 交错布局，桌面端左右交替

## 可访问性

### 语义化 HTML
- 使用 `<section>` 标签包裹区块
- 使用语义化的 heading 层级
- 按钮包含可访问的文本标签

### 颜色对比度
- 浅色文字在深色背景上确保可读性
- 按钮有足够的对比度
- 渐变背景保证文字清晰度

### 键盘导航
- 所有按钮可通过键盘访问
- Tab 键导航顺序合理
